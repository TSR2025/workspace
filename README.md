## Guidelines for AI Sessions

To maintain structure and repo health during our collaborative sessions:

1.  **Respect Boundaries:** All new projects should begin in `01-backlog`.
2.  **State Transitions:** Explicitly confirm when moving a project from `backlog` -> `validation` -> `active`.
3.  **Cleanliness:** Do not create top-level directories outside the defined pipeline.
4.  **Context:** When discussing a project, prefix instructions with the project folder path to ensure context is maintained.
